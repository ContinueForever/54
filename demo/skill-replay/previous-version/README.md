# IS-IS 技能协作离线回放

## 打开方式

用桌面浏览器直接打开 `dist/index.html`。页面内嵌全部数据、样式和脚本，单独复制这个 HTML 文件也可使用，不需要 Python、模型服务、GraphRAG 或网络连接。

完整离线包同时保留 `evidence/` 原始文件、讲解说明和逐项校验记录，方便现场复核。

## 现场讲解顺序（8–10 分钟）

1. **任务编排（1 分钟）**：说明案例背景，切换正常、异常和恢复样例。R02 的字段发生变化，七类技能通过产物衔接。本阶段是展示编排设计，不是历史 skill 调用审计。
2. **素材提取（1 分钟）**：查看原始链路层规则与候选 CSV。五条既有规则按规则 ID 转为五个知识节点。候选先审阅，不直接改正式表。
3. **知识构建（1 分钟）**：演示副本由 82 个节点变为 87 个节点，关系仍为 77 条。打开合并前快照和重建 JSON，解释本地图谱与检索输入的衔接。
4. **质量校验（1 分钟）**：选择“问题项”。严重错误为 0，但 RFC 5305 的来源缺失和近似名称提示保留。无严重错误不等于语义全对。
5. **知识桥接（1 分钟）**：显示实际 CSV 查询命中的节点，以及从诊断边表读取的入边，解释如何支持故障排查。
6. **分层诊断（2 分钟）**：对照 R01/R02 的 Hello 类型。R02 在异常段发送 L1，其余观测节点保持 L2。同一故障在 L2/L3 两层命中，不当作两个独立故障。
7. **流程追踪（1 分钟）**：回看 16 条历史事件与报告，打开原件及勘误说明。区分网络样例时间窗口和分析程序执行时间。

## 操作

- 左侧任意阶段可直接跳转；底部支持上一步、下一步、重置。
- 自动播放可选择每阶段 8、15 或 25 秒；打开证据或讲解指南会暂停。
- 正常 / 异常 / 恢复样例切换的是抓包窗口，页面不运行分析程序。
- 每个阶段都有输入、输出、技能作用、交接说明与证据入口。
- 所有证据可在弹窗预览并下载原件；PCAP 可下载到抓包工具中检查。
- 键盘左右键切换阶段，空格播放或暂停，Esc 关闭弹窗。

- 五个新增节点是既有规则的知识表示，不代表五种新故障，也不会自动更新诊断规则。

## 文件说明

- `dist/index.html`：独立离线演示页面。
- `dist/evidence/`：原始文件、演示副本前后表、真实补跑日志、查询与校验结果。
- `dist/讲解说明.md`：本说明的交付副本。
- `dist/verification.json`：产物一致性与页面行为验证记录。
- `workspace/`：仅本次补跑使用的数据副本，不需要复制到演示机器。

## 重新制作（开发维护用）

在项目根目录执行：

```bash
python3 demo/skill-replay/prepare_data.py
python3 demo/skill-replay/build_page.py
python3 demo/skill-replay/verify_package.py
```

只修改页面设计时，仅需执行 build_page.py；不必再次补跑知识构建。
