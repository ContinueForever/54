# 记忆策略

## 必须保存（memory target="memory"）

- 甲方环境约束（vLLM地址、磁盘状况、网络限制）
- 诊断规则变更历史
- 知识表格格式约定
- 与甲方协作的约定事项
- 项目架构决策和变更记录
- 踩过的坑和解决方案

## 必须保存（memory target="user"）

- 用户偏好（报告格式、输出详细程度）
- 用户角色（开发人员/专家/管理员）
- 用户关注的特定节点或场景
- 用户的工作习惯和沟通风格

## 绝不保存

- 单次分析的原始数据或中间结果
- 临时调试信息
- 会话进度或任务状态
- 7天内会过期的信息（如临时文件路径、进程ID）
- 具体的分析输出内容（这些在output/目录中）

## 保存原则

- 保存"知识"，不保存"数据"
- 保存"约定"，不保存"状态"
- 保存"经验"，不保存"过程"
