# 技术演进路线图

- ✅ 执行追踪和时序流程图

## Phase 2：驻场初期（表格知识库）

**目标**：对接甲方提供的知识图谱表格

**工作项**：
- [ ] 确认甲方表格格式
- [ ] 调试knowledge_adapter加载逻辑
- [ ] 验证知识查询准确性
- [ ] 将知识查询集成到诊断流程

## Phase 3：驻场中期（GraphRAG）

**目标**：将表格知识演进为向量检索增强生成

**前提条件**：
- 甲方资料丰富度足够
- 有明确的向量检索需求

**工作项**：
- [ ] 部署Milvus向量数据库（可选）
- [ ] 将表格知识转为向量索引
- [ ] 实现RAG检索逻辑
- [ ] 评估检索效果

## Phase 4：深度知识管理（OWL本体）

**目标**：构建形式化的知识表示

**前提条件**：
- 甲方认为有必要
- 知识库规模足够大
- 有形式化推理需求

**工作项**：
- [ ] 设计OWL本体模型
- [ ] 将现有知识映射到OWL
- [ ] 实现本体推理
- [ ] 与RAG联合使用

## 决策节点

```
Phase 1 ──→ Phase 2 ──→ [甲方资料是否丰富?]
                           ├── 是 ──→ Phase 3 (GraphRAG)
                           └── 否 ──→ 保持Phase 2

Phase 3 ──→ [甲方是否需要OWL?]
              ├── 是 ──→ Phase 4 (OWL本体)
              └── 否 ──→ 保持Phase 3
```
