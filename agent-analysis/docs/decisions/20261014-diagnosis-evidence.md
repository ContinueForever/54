# 诊断证据与工作台记录

为从原始症状展示诊断能力，本次输入增加可选 `network-state.json`。该文件作为只读证据进入特征和模型上下文，包含观测到的接口、配置、邻接和路由快照。

日志保留完整原文，避免事件解析丢失配置提交等上下文。知识查询同时使用日志事件与报文信号，因此不要求日志提前写出故障名称。

规则按故障名称归并为候选模式；跨层命中和业务后果不直接判成独立复合根因。无规则命中只表示现有规则未覆盖该异常，不称全面正常。

每次模型阶段保存提示、来源、参数、返回与时间，不保存密钥。示例适配器明确标注未调用配置模型；真实调用失败采用 ERROR 状态。工作台由正常项目输出目录的同一次运行生成，离线版本为这些记录的快照。

场景 PCAP 支持标准 IEEE 802.3 / LLC；旧 0xFEFE 归档仍可解析。合成窗口相对于捕获首包，不能解释为对任意现场抓包自动识别真实故障边界。

甲方数据始终只读，未操作网络设备。本次生成仅用于受控功能验证。知识准备在副本中执行，正式知识表不变。
